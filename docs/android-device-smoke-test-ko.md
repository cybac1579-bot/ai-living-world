# AI Living World v1.3 — Galaxy S25+ 오프라인 APK 실기기 검증

이 문서는 **개발용 오프라인 APK**의 수동 설치·검사표야. 성공한 클라우드 빌드가 실제 휴대폰 실행을 보장하지는 않아.

## 설치 전

- GitHub 비공개 저장소의 **Releases**에서 가장 최근의 `offline-debug-...` 사전 출시 버전을 선택해 `app-debug.apk`를 받아.
- Android의 외부 APK 설치 허용은 필요한 앱에만 일시적으로 활성화하고, 설치가 끝난 뒤 다시 꺼.
- 이 버전은 ChatGPT 로그인과 온라인 GPT 대화가 **의도적으로 비활성화**된 테스트판이야.
- 계정 비밀번호, API 키, OAuth 토큰, 개인정보를 입력하지 마.
- 가능하면 기존 설치판의 저장 데이터를 먼저 백업해. 디버그 빌드 교체 시 데이터 호환성을 아직 검증하지 않았어.

## 확인 항목

- [ ] 앱 설치에 성공하고 처음 실행했을 때 즉시 종료되지 않는다.
- [ ] Galaxy S25+ **세로 화면**에서 제목, 설명, 인물 대사, 선택지, 입력창과 하단 버튼이 잘리지 않는다.
- [ ] 화면 이동과 스크롤이 끊김 없이 동작한다.
- [ ] 대화가 여러 줄로 길어져도 말풍선·버튼이 겹치지 않는다.
- [ ] 키보드를 열고 닫아도 입력창과 주요 버튼을 사용할 수 있다.
- [ ] 오프라인 장면이나 선택지 등 가능한 상호작용이 정상 동작한다.
- [ ] 로그인·온라인 GPT 기능이 실행되지 않는다(현재 단계에서는 정상 동작).
- [ ] 앱에서 제공하는 로컬 저장 기능이 동작한다.
- [ ] 앱을 완전히 종료한 뒤 다시 실행해도 저장 내용이 유지된다.
- [ ] 휴대폰을 잠갔다가 돌아와도 충돌이나 화면 손상이 없다.

## 문제를 발견했다면

어떤 화면에서 어떤 버튼을 눌렀는지, 실제 결과와 기대한 결과, 앱 재시작 후 재현 여부를 함께 남겨줘. 화면이 잘리거나 겹치면 스크린샷이 가장 도움이 돼. 계정 정보나 개인 대화 내용은 가리고 전달해.

## 개발 단계 구분

1. CI에서 소스 검사·회귀 테스트·오프라인 APK 빌드·네트워크 권한 검증
2. Galaxy S25+ 실제 설치, 세로 레이아웃, 동작 및 저장 검증
3. Android 인증·암호화 보안 재검토 후 별도 온라인 GPT 테스트판 구축
4. 장기 캐릭터 기억, 대화/장면 연속성, 세계 상태 보존 및 이미지 연출 검증
