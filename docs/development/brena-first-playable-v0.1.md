# AI Living World — 브레나 중심 1차 플레이본 개발 기준 v0.1

기준일: 2026-11-23
상태: 개발 계획/수용 테스트 정의 (구현 완료 주장 아님)

## 확인된 기존 프로젝트
- GitHub README에 따르면 Android/Chaquopy 기반 개발 소스 스냅샷 `source/AI_Living_World_Android_v1.3.zip`이 있으며, 오프라인 디버그 APK 빌드와 238개 Python 회귀 테스트 통과 이력이 있다.
- Galaxy S25+ 실기기 실행/저장 검증은 README 기준 미완료다.
- 온라인 로그인과 GPT 호출은 보안 검증 전까지 디버그 빌드에서 비활성화한다.
- 기존 ZIP을 코드로 해제하여 실제 세계 엔진 구현 지점을 검사하기 전에는 브레나 시뮬레이션이 구현됐다고 주장하지 않는다.

## 1차 범위
- 브레나 마을의 확정 시설(광장, 잡화점, 작은 여관, 대장간, 촌장 집, 경비대 훈련 장소)과 상대적 위치 관계를 유지한다.
- 외부 지역 콘텐츠 개발은 보류하되 세계관상 출입 금지로 확정하지 않는다.
- 라나와 촌장은 주요 인물로 유지한다. 필수 시설 담당 NPC는 필요한 최소 기능부터 제공하고 이름·성별·외형·성격은 미정으로 둔다.
- 기타 주민은 주민 A·주민 B 등 안정적 식별자와 최소한의 현재 상태·기억으로 관리한다.
- 라나의 다섯 기본 활동: 주민 돕기·일감 수행, 창술 훈련, 촌장 집 생활, 주민 교류, 휴식·개인 시간.
- NPC의 독립적 행동은 **게임 내 시간이 진행될 때** 발생한다. 앱 종료 중 시간은 흐르지 않으며 오프라인 정산을 하지 않는다.
- 플레이어의 행동·발언·감정·출신을 AI가 임의 결정하지 않는다.
- 라나와 플레이어의 첫 만남은 고정 이벤트가 아니다.

## 최소 기능의 권장 구현 순서
1. 기존 엔진·UI·저장 포맷을 실제로 읽고 재사용 가능한 기능 식별
2. 게임 시간 진행 API와 앱 종료 중 시간 정지 검증
3. 브레나 장소/이동 상태 및 필수 시설 상호작용
4. 라나의 상황 기반 활동 선택과 위치/행동 일관성
5. 기타 주민의 간략 활동과 사건·관계·기억 기록
6. 비주얼 노벨 대화창 연동, 저장/복원 및 모바일 실제 검증

## 수용 테스트
- 앱을 종료했다 재실행해도 게임 시각이 자동으로 증가하지 않는다.
- 플레이어가 시간을 진행할 때만 NPC 상태가 변경된다.
- 플레이어가 대화하지 않아도 NPC가 유효한 활동을 수행할 수 있다.
- 라나는 하루에 다섯 활동을 모두 강제로 수행하지 않고 상황에 따라 선택한다.
- 같은 NPC의 이전 약속·사건 결과가 저장/복원 후에도 유지된다.
- 기타 주민의 활동에 별도 상세 전기나 전용 이미지가 필요하지 않다.
- 플레이어의 위치·발언·감정을 자동으로 서술하지 않는다.
- 첫 만남을 강제하는 이동/순간이동/이벤트가 없다.
- 확정하지 않은 시설·주민 신상·사건을 정설로 만들지 않는다.
