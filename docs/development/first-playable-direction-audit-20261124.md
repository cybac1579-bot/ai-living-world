# AI Living World — 최초 목표 대비 개발 방향 점검 (2026-11-24)

## 판정
세계관, 플레이어 권한, 시간 정지, 라나의 자율성, 관계 확장 목표는 기존 기준 문서와 일치한다. 그러나 최근 작업은 APK 패키징·시작 경로·저장 검증에 집중되어 NPC 독립 행동과 GPT 대화가 Android 실제 플레이에 연결되지 않았다. 개발 우선순위를 교정한다.

## 반드시 유지
- Android 세로형 비주얼 노벨과 실제 일러스트, 화자별 이름·색상 대화창
- 브레나와 라나 중심의 독립 NPC 일상, 관계, 사건, 장기 기억
- 명시적 게임 시간 진행만 허용, 종료 중 시간 정지
- 플레이어 행동·발언·감정·출신을 AI가 임의로 만들지 않음
- NPC와 플레이어의 정보·지식 경계, 첫 만남과 연애·결혼 비강제
- 자유입력 GPT 대화와 장기 기억, 결혼 이후 계속되는 생활과 관계 확장성

## 확인한 미완료
1. 시간 진행 UI/API 코드 존재. 최신 APK·에뮬레이터·실기기 실행은 미검증.
2. NPC 이동 후보 변환기는 존재하나 원본 EventStore의 실제 NPC 이벤트 커밋과 미연결.
3. 라나 활동 표시는 원형 투영을 사용. 저장된 NPC 상태와 모순 없이 연동해야 함.
4. GPT 대화와 브레나 기억·관계·사건의 왕복 연결은 미검증.
5. Galaxy S25+에서 연속 플레이와 이미지·대화창 표현은 미검증.

## 우선순위 재정렬
1. 최신 CI 오류 수정 및 엔진 전이 규칙 확인.
2. 명시적 10분 진행에서 NPC 행동·이동을 원본 EventStore에 유효하게 기록. 실패 시 부분 커밋 금지.
3. 실제 저장된 NPC 상태의 UI 반영 및 재시작 복원.
4. 라나 자유입력 대화와 기억·관계의 실제 통합. 보안 검증 전 온라인 디버그 비활성 유지.
5. 비주얼 노벨 대화창·이미지 및 실기기 20~30분 연속 플레이 검증.
6. 장기 관계·결혼 이후 생활과 1년 일관성 확장.

## 보고 원칙
테스트 코드 추가, 테스트 통과, APK 패키징, 실제 Android 플레이 검증을 각각 구분한다. 세계관의 새로운 사실은 이 문서로 임의 확정하지 않는다.
