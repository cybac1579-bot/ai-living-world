# AI Living World — 라나 중심 관계·시각 연출 1차 플레이본 우선순위 v0.1

기준일: 2026-11-24
상태: 사용자 확정 개발 우선순위 / 신규 세계관 사실 확정 아님

## 사용자 확정 방향
- 세계 전체의 자율적 변화와 인물 관계의 깊이는 모두 중요하다.
- **1차 플레이본은 라나와 깊은 관계를 형성하는 경험을 먼저 검증**한다.
- **그래픽 표현은 부가 장식이 아니라 핵심 플레이 경험**이다.
- 세계의 독립성, 라나의 개인 목표, 플레이어의 선택권을 희생하면서 관계 이벤트를 강제하지 않는다.

## 수용 기준 — 첫 20~30분 체험
1. 플레이어가 라나를 만날 수도, 만나지 않을 수도 있다. 강제 첫 만남 없음.
2. 만났다면 대화 내용과 반응이 라나의 현재 장소·활동·기억·관계에 맞아야 한다.
3. 플레이어가 명시적으로 입력/선택한 말과 행동만 저장한다.
4. 라나의 반응이 대사 내용 외에도 표정·시선·자세·거리감·화면 연출에 반영되어야 한다.
5. NPC 대사는 화자 이름과 은은한 배경의 전용 대화창으로 표현하고 상황 묘사와 분리한다.
6. 세계의 시간은 명시적 진행으로만 흐르고, NPC는 독립적 목표와 일상을 유지한다.
7. 앱 재시작 뒤에도 사건·관계·NPC 위치와 게임 시간이 일관되어야 한다.
8. 승인된 라나 디자인 시트와 일치하는 실제 게임 에셋이 포함되어야 한다. 이미지가 없다면 임시 이미지임을 명확히 표시한다.
9. 20~30분 체험 뒤 플레이어가 다시 라나를 만나고 싶어지는지 질적으로 평가한다. 호감도 상승 횟수만으로 성공 판정하지 않는다.

## 그래픽 구현 순서
P0. 승인된 디자인 시트 원본 파일 위치와 재사용 권한/해상도/버전 확인. 원본 없이 새 정본 외형 생성 금지.
P1. 모바일 세로 화면의 VN 대사창(화자 이름, 인물별 배경색), 상황 묘사 분리 및 라나 캐릭터 스탠딩 배치.
P2. 기본 표정/자세 변형과 관계·상황별 시각 상태 선택. 확정되지 않은 감정은 단정하지 않는다.
P3. 브레나 주요 배경의 시간대별 조명과 전환 효과. 실제 에셋 포함 여부를 APK에서 검증.
P4. 관계 변화의 과장 없는 시각 연출 및 저장/복원 테스트.

## 개발 주의
- 정해진 호감도 숫자만으로 자동 고백/연애/결혼 이벤트를 만들지 않는다.
- 외형 변경과 NPC 감정 변화는 실제 사건/상황에 근거해야 한다.
- 텍스트만 있는 테스트 화면을 완성된 VN으로 보고하지 않는다.
- 보안 검증 전 온라인 GPT 로그인/호출은 디버그에서 비활성 유지.
- CI에서 Android 의존성 Maven 429 발생 시 코드 실패와 분리해서 기록한다.
- 승인된 라나 디자인 시트가 실제 저장소에 없으면 이미지 삽입 성공을 주장하지 않는다.

## 현재 확인한 기술적 상태
- 기존 브레나 저장/시간/NPC 이동 및 대화 준비·검증 모듈은 구현됨.
- 실제 GPT 대화 및 관계 기억의 완전한 왕복 연동은 미완료.
- 2026-11-24 안정성 워크플로 중 APK 빌드가 Maven HTTP 429로 실패한 실행이 있음. 다른 실행의 통과 기록과 구분.
- Galaxy S25+ 실기기 연속 플레이와 승인된 라나 원화의 APK 내 실제 출력은 미검증.
