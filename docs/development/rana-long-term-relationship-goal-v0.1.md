# AI Living World — 라나 장기 관계 시뮬레이션 목표 v0.1

작성일: 2026-11-23
상태: 사용자 의도/개발 목표와 미정 세계관 사실을 구분

## 사용자 의도 — 확정된 개발 목표
- 브레나 마을에서 1년간 지낼 수 있는지를 먼저 검토한 이유는, 플레이어가 마을에 머무르며 라나와 친해지고 관계가 깊어져 **최종적으로 결혼까지 가능할 정도의 깊이**를 가진 캐릭터를 먼저 만들고 싶기 때문이다.
- 이렇게 만든 깊이 있는 캐릭터·관계 시스템을 이후의 세계와 콘텐츠 확장에도 활용하기 쉽도록 설계한다.
- 이는 '1년 내 반드시 결혼', '결혼이 정해진 정사', '라나가 반드시 플레이어를 사랑한다'는 설정이 아니다.
- 플레이어 행동·감정·대사·의도는 자동 결정하지 않는다. 라나의 독립적인 목표와 판단을 유지한다.

## 설계상 필수 검토 항목 (세부 사양 미확정)
- 만남/대화/일상 공유/신뢰/갈등/화해/연애/상호 동의에 따른 결혼 가능성과 이후 생활까지 관계 상태를 유지할 수 있는지.
- 관계가 바뀌더라도 라나의 창술 훈련·경비대 입단 목표, 촌장과의 관계, 주민과의 일상은 소거하지 않는다.
- 사건·약속·대화·관계 변화의 장기 기억과 저장/복원 일관성.
- 관계 발전을 고정 일수나 단일 호감도 수치로 강제하지 않고 인물 선택과 사건의 맥락을 고려.
- 계절·일상 반복과 변화가 1년 규모에서도 모순 없이 유지되는지 검증. 365개의 개별 이벤트를 사전 작성한다는 뜻은 아니다.
- 결혼 이후의 주거, 경제, 가족 관계, 생활 방식 등 구체적 세계관 설정은 미정이며 자동 확정하지 않는다.

## 우선 개발 순서 제안
1. 브레나 장소·게임 시간·라나 활동·기억/관계 기록을 먼저 연결
2. 며칠~수주 단위로 플레이어와 라나의 상호작용 및 갈등·약속 지속성 검증
3. 상호 동의 기반 관계 변화와 장기 상태 전이 검증
4. 결혼과 결혼 이후 일상까지 상태/대사/생활의 일관성을 검증
5. 장기 1년 시뮬레이션에서 기억·반복·시간·상태 모순 검사

## 아직 결정하지 않은 것
- 플레이어와 라나의 첫 만남, 관계 결과, 결혼 시점, 고백 방식, 라나의 실제 반응, 고정 연애 이벤트.
- 구체적인 결혼 관습·혼인 제도, 신혼집, 자녀, 임신 등은 사용자 확인 전 세계관으로 만들지 않는다.

## 추가 확정 — 2026-11-23
- 라나와 결혼한 이후에도 게임이 계속되며, 향후 하렘 루트도 가능한 관계 시스템을 고려한다.
- 하렘 성립, 라나의 수용, 결혼 제도 등은 아직 확정되지 않았다.
