# AI Living World 안정성 게이트 도입 (2026-11-23)

## 목적
개발 브랜치에서 테스트를 통과한 뒤 main으로 반영하는 절차를 시작한다.
**이 문서나 워크플로만으로 GitHub의 main 브랜치 보호가 설정된 것은 아니다.**
관리자 설정의 필수 검사 및 PR 리뷰 요구 여부는 별도로 확인해야 한다.

## 보호해야 하는 데이터
- main의 정상 실행 이력이 있는 커밋/태그를 복구 기준으로 기록한다.
- 게임 저장 파일은 향후 원자적 교체, 이전 정상 저장 복사본, 버전별 마이그레이션을 갖춘다.
- 비밀키, 로그인 정보, 개인 대화 저장은 GitHub에 커밋하지 않는다.
- 관계, 약속, NPC 기억은 기존 저장과의 호환성을 테스트한다.

## 코드 변경 체크리스트
1. docs/development/PROJECT_SOURCE_OF_TRUTH.md와 확정 설정을 확인한다.
2. 작업 브랜치를 최신 main에서 생성하고 기존 기능과 충돌을 검토한다.
3. 문법 검사 및 회귀 테스트 실행 후 PR로 제안한다.
4. CI 통과와 실제 Android 실행/실기기 검증을 별개로 보고한다.
5. 검증 실패 시 main 병합 금지, 원인 분석과 수정 우선.
6. 정상 동작 기준을 확인한 커밋/태그를 복구 지점으로 보존한다.

## 이번 적용 범위
- `.github/workflows/stability-gates.yml`은 Python 원형의 문법, 세계/대화 회귀 테스트, 플레이어 행동 자동 생성 방지의 최소 검사다.
- **Android 전체 빌드·실기기·AI 응답 의미 검증·저장 마이그레이션까지 통과시켜 주는 것은 아니다.**
- main 브랜치 보호와 필수 상태 검사는 GitHub 저장소 설정 확인 및 필요 권한이 남아 있다.
