# AI Living World — 독립적으로 변화하는 세계 v0.1

상태: 사용자 확정 원칙과 구현 권고를 구분
최종 갱신: 2026-11-23

## 사용자 확정 — 세계 운영 원칙
- 플레이어가 아무 행동도 하지 않아도 NPC는 독립적으로 생활한다.
- NPC 사이의 관계와 세계의 사건은 플레이어의 개입 없이도 자연스럽게 변화할 수 있다.
- 플레이어가 행동하지 않는다는 이유로 세계의 시간을 정지시키거나 NPC를 플레이어 대기 상태로 만들지 않는다.
- 독립적인 변화가 반드시 매일 큰 사건을 의미하지는 않는다. 평범하고 조용한 날도 가능하다.
- 플레이어의 행동·발언·감정·의도·출신은 AI가 임의 결정하지 않는다.
- 플레이어가 알지 못하는 사건과 플레이어가 실제로 인지한 사건을 구분한다. NPC가 모르는 사실을 알고 있는 것처럼 행동시키지 않는다.
- 브레나 마을을 포함한 세계 전반에 적용한다. 브레나의 라나는 확정된 일상 활동 다섯 가지와 유동적 우선순위에 따라 생활하며 플레이어를 만나도록 강제 배치하지 않는다.

## 검토한 장점
- NPC와 세계의 독립성·생활감 증대 (영향도 매우 큼).
- 재방문 시 누적된 관계·상황 변화와 발견의 재미 (큼).
- NPC 자신의 선택이 이야기의 원인이 되는 상호작용 (매우 큼).

## 검토한 위험
- 위치·기억·관계·시간의 상태 모순 (매우 큼).
- 플레이어가 모르는 사이 중요한 사건이 지나가는 문제 (큼).
- 모든 NPC를 매 순간 상세 생성할 때 비용·복잡도 급증 (매우 큼).
- 과도한 사건 빈도로 평범한 생활의 개연성 저하 (큼).

## 구현 권고 — 아직 사용자 확정된 세부 사양 아님
- 활동·위치·관계·사건 결과는 검증 가능한 구조화 상태와 시간 기록으로 관리한다.
- 일상적인 시간 흐름은 간결하게 갱신하고 주요 상호작용에서 상세 장면을 생성하는 단계적 시뮬레이션을 검토한다.
- 사건이 발생한 시각, NPC의 인지 여부, 지속 효과를 구분하고 중복·모순을 검증한다.
- 플레이어에게 중요한 사건의 전달 방식과, 오프라인/장시간 시간 경과의 진행·요약 범위는 별도로 결정한다.
- 실제 엔진의 장기간 시뮬레이션 구현과 검증은 아직 완료되었다고 간주하지 않는다.
