# AI Living World — 독립적으로 변화하는 세계 v0.3

상태: 사용자 확정 원칙과 구현 권고를 구분
최종 갱신: 2026-11-23

## 사용자 확정 — 세계 운영 원칙
- 플레이어가 아무 행동도 하지 않아도 NPC는 독립적으로 생활한다.
- NPC 사이의 관계와 세계의 사건은 플레이어의 개입 없이도 자연스럽게 변화할 수 있다.
- **게임을 종료한 동안에는 게임 내 시간이 흐르지 않는다.** 게임을 실행하고 플레이어가 게임 내 시간을 진행할 때 세계가 변화한다. (사용자 확정 B안)
- **게임 내 시간이 진행되는 동안** 플레이어가 아무 행동도 하지 않더라도 NPC는 독립적으로 활동한다. NPC를 플레이어 대기 상태로 만들지 않는다.
- 독립적인 변화가 반드시 매일 큰 사건을 의미하지는 않는다. 평범하고 조용한 날도 가능하다.
- 플레이어의 행동·발언·감정·의도·출신은 AI가 임의 결정하지 않는다.
- 플레이어가 알지 못하는 사건과 플레이어가 실제로 인지한 사건을 구분한다. NPC가 모르는 사실을 알고 있는 것처럼 행동시키지 않는다.
- 브레나 마을을 포함한 세계 전반에 적용한다. 브레나의 라나는 확정된 일상 활동 다섯 가지와 유동적 우선순위에 따라 생활하며 플레이어를 만나도록 강제 배치하지 않는다.

## 초기 개발 범위에 관한 사용자 의도
- 브레나 마을 내부에 머무르는 플레이를 우선 검증해 외부 지역·탐험·추가 캐릭터·몬스터·아트 리소스 부담을 줄이는 것이 목적이다.
- **마을 밖으로 이동할 수 없다는 영구적인 세계관 제약은 확정하지 않았다.** 브레나 중심의 1차 플레이 범위와 추후 외부 확장은 구분한다.
- 1년 분량의 고정 사건이나 모든 주민의 상세 설정을 처음부터 요구하지 않는다. 구체적인 1차 구현 범위는 개발 계획에서 별도로 결정한다.

## NPC 설정 깊이 — 사용자 확정
- 모든 주민에게 상세한 개별 설정을 만들 필요는 없다. 일반 주민은 **주민 A·주민 B 등 기타 인물**로 운영해도 된다.
- **필수 시설 담당 NPC**와 **이야기 전개에 필수적인 주요 인물**만 별도의 필요한 설정을 만든다.
- 기타 인물도 독립적으로 생활하고 기존에 발생한 상호작용·사건의 결과를 일관되게 유지해야 한다. 상세한 과거나 전용 일러스트가 필수인 것은 아니다.
- 기타 주민의 구체적인 인원수·고유 이름·외형·세부 성격은 자동 확정하지 않는다. 시설 담당 NPC의 고유 이름·성별·성격도 아직 미정이다.

## 구현 권고 — 확정되지 않은 세부 설계
- 주요 인물 / 필수 시설 담당 / 기타 주민의 세 단계 데이터 구조를 검토한다. 이는 사용자 의도를 구현하기 위한 제안이며 고정된 세계관 계급은 아니다.
- 기타 주민에게 안정적인 내부 식별자와 최소 상태·기억을 부여하고, 중요해진 인물만 상세 설정을 확장하는 방식을 권장한다.

## 검토한 장점
- NPC와 세계의 독립성·생활감 증대 (영향도 매우 큼).
- 재방문 시 누적된 관계·상황 변화와 발견의 재미 (큼).
- NPC 자신의 선택이 이야기의 원인이 되는 상호작용 (매우 큼).

## 검토한 위험
- 위치·기억·관계·시간의 상태 모순 (매우 큼).
- 플레이어가 모르는 사이 중요한 사건이 지나가는 문제 (큼).
- 모든 NPC를 매 순간 상세 생성할 때 비용·복잡도 급증 (매우 큼).
- 과도한 사건 빈도로 평범한 생활의 개연성 저하 (큼).

## 구현 권고 — 아직 사용자 확정된 세부 사양 아님
- 활동·위치·관계·사건 결과는 검증 가능한 구조화 상태와 시간 기록으로 관리한다.
- 일상적인 시간 흐름은 간결하게 갱신하고 주요 상호작용에서 상세 장면을 생성하는 단계적 시뮬레이션을 검토한다.
- 사건이 발생한 시각, NPC의 인지 여부, 지속 효과를 구분하고 중복·모순을 검증한다.
- 플레이어에게 중요한 사건의 전달 방식과, 게임 내 장시간 진행 시의 요약 범위는 별도로 결정한다. **오프라인 중 경과 시간 정산은 하지 않는다.**
- 실제 엔진의 장기간 시뮬레이션 구현과 검증은 아직 완료되었다고 간주하지 않는다.
